# Prototype CRM System

โปรเจกต์นี้เป็นต้นแบบเว็บแอปพลิเคชัน CRM (Customer Relationship Management) ที่สร้างด้วย PHP แบบไฟล์เทมเพลตพื้นฐานและ Bootstrap โดยมีการกำหนดหน้าเพจผ่าน `public_html/index.php` ด้วยพารามิเตอร์ `?page=`.

## โครงสร้างโปรเจกต์

```
prospectlist/
├── config/db.php        # เชื่อมต่อฐานข้อมูล (อ่านค่าจาก .env)
├── public_html/         # Document root ของเว็บ (เปิดผ่านเว็บได้เฉพาะโฟลเดอร์นี้)
│   ├── index.php        # Front controller จุดเข้าเดียวของทุก request
│   ├── css/  js/
├── src/Actions/         # สคริปต์ประมวลผลฟอร์ม/ลบ/นำเข้า/ส่งออก เรียกผ่าน ?route=ชื่อไฟล์
├── templates/           # หน้าเว็บ เรียกผ่าน ?page=ชื่อไฟล์ (layout.php = โครงหลัก)
├── .env                 # ค่าฐานข้อมูลจริง (ห้าม commit) ดูตัวอย่างใน .env.example
├── composer.json        # ต้องการ PHP ^8.4
└── backup/27-10-69/     # สำเนาโค้ดก่อนปรับโครงสร้าง ลบได้เมื่อทดสอบบนเซิร์ฟเวอร์แล้ว
```

- `index.php?page=products` → แสดง `templates/products.php`
- `index.php?route=product_delete&id=5` → รัน `src/Actions/product_delete.php`
- ทุก route ต้องล็อกอินก่อน ยกเว้น `login_action`; ชื่อ page/route รับเฉพาะ `a-z` และ `_`

## ฟีเจอร์ที่มีอยู่

### หน้าเข้าสู่ระบบ
- มีฟอร์ม username/password
- แสดงข้อมูลตัวอย่าง Demo Credentials
- หน้า Login แยกโครงสร้างการแสดงผลออกจากหน้าหลัก

### จัดการสินค้า
- หน้ารายการสินค้าพร้อมตารางข้อมูลตัวอย่าง
- ฟอร์มเพิ่มสินค้าใหม่
- ฟีเจอร์นำเข้าไฟล์ (Import CSV/Excel) ในฟอร์มเพิ่มสินค้า

### จัดการลูกค้า
- หน้ารายการลูกค้าในรูปแบบตาราง
- ฟอร์มเพิ่มลูกค้าใหม่ พร้อมข้อมูลจังหวัด อำเภอ โรงพยาบาล แผนก รายชื่อ และเบอร์โทร
- ฟีเจอร์นำเข้าไฟล์ลูกค้า

### จัดการพนักงาน
- หน้ารายการพนักงานพร้อมตารางข้อมูลตัวอย่าง
- ฟอร์มเพิ่มพนักงานใหม่ พร้อม SR.NO, ชื่อ, อีเมล, ตำแหน่ง, Username และ Password

### การติดต่อลูกค้า
- หน้าตารางบันทึกการติดต่อพร้อมข้อมูลตัวอย่าง
- ฟอร์มเพิ่มการติดต่อลูกค้า แบ่งเป็น 2 ส่วน
  1. ข้อมูลการเสนอราคา: พนักงาน, วันที่เสนอ, เลขที่เสนอ, โรงพยาบาล, ลูกค้า, สินค้า, รุ่น, ราคา
  2. การติดตาม/สถานะงาน: วันที่รายงาน, คู่แข่ง, โอกาส, สถานะงาน, กิจกรรมล่าสุด, แผนถัดไป, ปัญหา, การสนับสนุน, วันที่คาดว่าจะปิดได้

### รายงาน
- หน้ารายงานการติดต่อ
- ปุ่ม Export CSV / Export Excel
- ตารางข้อมูลตัวอย่างสำหรับดูรูปแบบรายงาน

## หมายเหตุสำคัญ

- แอปนี้เป็นต้นแบบที่เน้นการแสดงผลด้วยเทมเพลต โดยยังไม่มีระบบฐานข้อมูลหรือ backend processing ที่ชัดเจน
- `public_html/index.php` ทำ routing แบบพารามิเตอร์เดียว และโหลดเทมเพลตตามค่า `page`
- ข้อมูลในหน้า `products`, `customers`, `employees`, `contacts`, `reports` เป็นข้อมูลตัวอย่างที่ฝังใน HTML
- หากต้องการใช้งานจริง ควรเพิ่ม:
  - ระบบเก็บข้อมูลในฐานข้อมูล
  - การตรวจสอบบัญชีผู้ใช้ (authentication)
  - การประมวลผลฟอร์ม POST
  - การจัดการไฟล์นำเข้า CSV/Excel

## วิธีใช้งานเบื้องต้น

1. ต้องใช้ PHP 8.4 ขึ้นไป (ทดสอบกับ 8.4.x)
2. คัดลอก `.env.example` เป็น `.env` แล้วใส่ค่าฐานข้อมูล
3. ตั้ง document root ของเว็บเซิร์ฟเวอร์ไปที่ `public_html/`
4. เปิด `http://localhost/` แล้วเข้าสู่ระบบ

## สรุป

โปรเจกต์นี้เป็นตัวอย่างระบบ CRM ที่มีหน้าเว็บสำคัญสำหรับสินค้า, ลูกค้า, พนักงาน, การติดต่อลูกค้า และรายงาน โดยโครงสร้างหลักอยู่ที่ `public_html/index.php` และเทมเพลตในโฟลเดอร์ `templates/`.
